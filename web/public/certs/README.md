# 证书图片放这里

把证书原图直接放到这个目录，文件名要和 `content/honors.yaml` 与
`content/profile.yaml` 里 `cert` 字段写的路径**完全一致**。

当前引用的是这两张：

| 文件名 | 用在哪 |
|---|---|
| `gd-skills-2026.png` | 广东省职业院校学生专业技能大赛 省一等奖 |
| `software-copyright-2026.png` | 计算机软件著作权登记证书 |

放进来之后刷新页面：
- **「关于我」屏** —— 「主修课程」下面会多出一张「证书 CERTIFICATES」卡片，
  两张证书的缩略图直接显示出来，点击看大图
- **「荣誉」屏** —— 点击对应条目打开同一张大图
- **「关于我」屏的数字徽章** —— 带 ⊕ 的徽章也能点开

## 格式说明

png / jpg 都行，但**文件名必须和 yaml 里写的一致**（包括扩展名）。
如果你的文件是 `.jpg`，要么改文件名成 `.png`，要么改 yaml 里的路径。

想换成 WebP 压体积的话，可以在 `scripts/prepare-assets.py` 的 `IMAGES`
列表里加两条映射，然后跑 `npm run assets`。

## 没放图片会怎样

不会报错。`honors.yaml` 里 `cert` 为 `null` 的条目点击无反应，
放了大图的条目右侧会多一个 `⊕` 提示。图片缺失时图裂，但页面其余部分正常。
