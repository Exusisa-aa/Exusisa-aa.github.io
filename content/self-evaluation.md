我大一的时候做过一些很有意思的项目，即使当时的我没学 AOP 思想，却已经用上了动态代理；即使没学 Tomcat，我也会用线程池启动我的项目；即使没学数据库，我却用 XML 的解析模拟了数据的存储，故我认为我还是对这行感兴趣的。

我刚接触这行的时候，AI 的发展已经初显端倪，但我不想随波逐流，让 AI 完全接管我的代码。作为一个成熟的全栈开发者，即使是 AI 即将取代前端和去 SQL 化的历史节点，我也要为了写出更好的后端代码，将生产的全栈知识和架构刻入大脑——我要让 Agent 工作流被我指挥，生产出符合后端开发架构体系的代码，再按我的知识体系审查，而不是被 Agent 工作流牵着鼻子走，并且要用一个成熟的后端开发者的视角看待 AI 应用开发和 Agent 工作流。
